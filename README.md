## What this repository is

This is the **Topological Photonic Lattice Explorer** with a full **stability-analysis suite**
added to the nonlinear side.

The base application — topological lattice construction (IQH / AQH, flat / superlattice /
cylinder / zigzag ribbon), linear transmission and Wigner delay, and driven Kerr frequency-comb
generation — is documented in the sibling repository:

> **[Topological_Photonics_Nonlinear_Explorer](https://github.com/lidaxu-physics/Topological_Photonics_Nonlinear_Explorer)**
> — the base explorer, with the physics background, Hamiltonian conventions and linear/nonlinear
> engines described in full.

**This repository adds one thing, and it is the reason it exists separately:** once a comb state
has been reached, is it actually *stable*, and in what sense? The nonlinear window here gains a
**Stability Analysis** entry point that answers that three different ways, behind a diagnostic
gate.

Everything else is shared with the base explorer. If you only want to generate combs, use that
one; if you want to interrogate what you generated, use this one.

## The stability suite

A comb sweep leaves behind a slow-time history `hist`. `Stability Analysis` opens on that
history and offers four tabs, deliberately in this order.

### 📐 Sampling check — *run this first*

**The diagnostic comes before the analysis, because it decides whether the analysis means
anything.**

A soliton sitting in a (near-)translationally-invariant system carries a **Goldstone mode**: the
zero eigenvalue generated by the freedom to translate it. That mode is the landmark you read the
rest of the spectrum against — but it only lands at zero if translation is well represented on
the grid. On a coarse grid, θ-translation is numerically broken, the Goldstone is no longer
protected, and it drifts down into the bulk continuum at `−κ` where it is indistinguishable from
an ordinary damped mode.

The tab measures samples-per-peak and grades the run:

| FWHM (grid points) | verdict |
|---|---|
| ≥ 8 | well-resolved — Goldstone should appear near 0 |
| 6 – 8 | marginal — Goldstone may or may not resolve |
| < 6 | under-resolved — Goldstone likely absorbed into the bulk |

If this tab says *under-resolved*, the Jacobian and Floquet spectra below are not trustworthy,
however clean they look. Re-run the sweep with a finer grid instead.

### 📈 Lyapunov — finite-time Lyapunov exponent (FTLE)

Direct trajectory-divergence measurement: evolve the state, repeatedly perturb by `ε` and
renormalize, and accumulate the growth rate. Controls are the integration length `T`, the number
of restarts `K`, a discarded `transient`, and the perturbation size as `log₁₀(ε)` (default
`1e-10`).

This is the assumption-free method — it does not care whether the state is a fixed point, a
breather, or chaotic. It is also the slowest, and it returns one number rather than a spectrum.

### 🔢 Jacobian — eigenspectrum at a fixed point

For **steady** states. Optionally runs a **Levenberg–Marquardt solve** first to relax the seed
onto a true fixed point of the nonlinear residual `da/dt = 0`, then evaluates the eigenvalues of
the continuous-time LLE Jacobian *of that residual* at the converged point.

Two details that matter:

- The LM solve uses the **true nonlinear residual and its exact Jacobian**, not a finite-difference
  approximation of either.
- The residual convention is matched to the one the stepper uses, so the eigenvalues correspond to
  the dynamics actually being simulated rather than to a differently-scaled model.

The seed is any slow-time step, and the operating point (`Δ`, `F`) at that step is displayed live
so it is always clear which point on the detuning schedule is being analysed.

### 🔄 Monodromy — Floquet multipliers

For **periodic** (breathing) states, where a fixed-point Jacobian does not apply. The algorithm:

1. Estimate the period `N_T` from the ESA of the history power — the first non-DC peak.
2. Take `ψ* = hist[:, :, seed_step]`.
3. Build the monodromy matrix column by column,
   `M[:, j] = (G^{N_T}(ψ* + ε·e_j) − ψ*) / ε`,
   where `G^{N_T}` is the split-step stepper run `N_T` times.
4. The eigenvalues `μ` of `M` are the **Floquet multipliers**. The state is stable when
   `|μ| ≤ 1` for all of them.

Because step 3 costs one full `N_T`-step propagation *per degree of freedom*, the tab first draws
a three-period oscilloscope trace and **waits for you to confirm the detected period looks right**
before committing to the build. Getting `N_T` wrong wastes the whole computation.

## Which tool for which state

| state | use |
|---|---|
| steady (CW, stationary soliton) | **Jacobian** — full eigenspectrum, fastest, most informative |
| periodic / breathing | **Monodromy** — Floquet multipliers |
| unknown, or suspected chaotic | **Lyapunov** — no structural assumption |

In all three cases, check **Sampling** first.

## Requirements

- Python 3.8+
- PyQt5, matplotlib, numpy, scipy

Optional, for GPU/XLA acceleration of the split-step stepper:

```bash
pip install jax jaxlib      # CPU
pip install jax[cuda12]     # NVIDIA GPU — match your CUDA version
```

JAX is genuinely optional: the import is guarded and the app falls back to NumPy automatically.
The Monodromy tab benefits most, since it runs the stepper once per degree of freedom.

## Running

From source:

```bash
python Linear.py
```

`Linear.py` is the entry point; `NonLinear.py` is loaded at runtime and carries the comb engine
and the stability suite.

To build a self-contained Windows executable (no Python needed on the target machine), see
[`BUILD_INSTRUCTIONS.md`](BUILD_INSTRUCTIONS.md):

```bash
pyinstaller TopologicalPhotonic.spec
```
